ကွန်ပျူတာကို ရွေးချယ်ပါ။

ရုံးလုပ်ငန်း၊ ကျောင်းသင်ကြားရေး၊ ဒီဇိုင်းဖန်တီးမှု၊ လုပ်ငန်းသုံး Software နဲ့ နေ့စဉ်အသုံးပြုမှုများအတွက် Desktop Computer နှင့် Laptop များကို သင့်လိုအပ်ချက်၊ အသုံးပြုပုံနဲ့ ဘတ်ဂျက်အလိုက် ရွေးချယ်နိုင်ရန် IT Garden က ကူညီပေးပါတယ်။

စက်တစ်လုံးကို ရွေးချယ်ရာမှာ Processor၊ RAM၊ Storage၊ Display နဲ့ အသုံးပြုမယ့် Software တွေကို ထည့်သွင်းစဉ်းစားဖို့ လိုပါတယ်။ IT Garden ကို သင့်လိုအပ်ချက်နဲ့ ဘတ်ဂျက် ပြောပြပြီးမှ သင့်တော်တဲ့ ရွေးချယ်မှုကို ဆွေးနွေးနိုင်ပါတယ်။

အရောင်းဝန်ဆောင်မှု

စက်ရွေးချယ်မှုကနေ ဝယ်ယူပြီးနောက်အထိ။

၀၁

လိုအပ်ချက် နားထောင်ပေးခြင်း

သုံးစွဲမယ့် ရည်ရွယ်ချက်၊ လိုအပ်တဲ့ စွမ်းဆောင်ရည်နဲ့ ဘတ်ဂျက်ကို အရင်ဆွေးနွေးပေးပါတယ်။

၀၂

မော်ဒယ်နှင့် ဈေးနှုန်း စုံစမ်းပေးခြင်း

ရရှိနိုင်တဲ့ မော်ဒယ်၊ Specification၊ Stock နဲ့ ဈေးနှုန်းကို အတည်ပြုပြီးမှ ရွေးချယ်နိုင်ပါတယ်။

၀၃

အခြေခံ Setup အကြံပြုခြင်း

စက်အသစ်စတင်အသုံးပြုရာမှာ လိုအပ်တဲ့ Software နဲ့ အသုံးပြုမှုဆိုင်ရာ အချက်များကို ဆွေးနွေးနိုင်ပါတယ်။

ဝယ်ယူပုံ အဆင့်ဆင့်

ရိုးရှင်းတဲ့ အဆင့် ၃ ဆင့်။

၀၁။ လိုအပ်ချက် ပြောပြပါ

Desktop သို့မဟုတ် Laptop၊ အသုံးပြုမယ့်အလုပ်နဲ့ ဘတ်ဂျက်ကို ပြောပြပါ။

၀၂။ ရွေးချယ်မှု အတည်ပြုပါ

မော်ဒယ်၊ Specification၊ Stock၊ ဈေးနှုန်းနဲ့ အာမခံစည်းကမ်းကို အတည်ပြုပါ။

၀၃။ ဝယ်ယူမှု ဆက်လက်ဆောင်ရွက်ပါ

အသေးစိတ်အချက်အလက်တွေ သဘောတူပြီးမှ ဝယ်ယူမှုကို ဆက်လက်ဆောင်ရွက်နိုင်ပါတယ်။

မေးလေ့ရှိသော မေးခွန်းများ

မဝယ်ယူမီ သိထားသင့်တာများ။

အသစ်နဲ့ အသုံးပြုပြီး စက်တွေ ရနိုင်ပါသလား?

မော်ဒယ်နဲ့ Stock အခြေအနေအလိုက် ရရှိနိုင်မှုကို စုံစမ်းပေးပါမယ်။ အခြေအနေကို မဝယ်ယူမီ ရှင်းလင်းအတည်ပြုပါမယ်။

စက်တစ်လုံးရဲ့ ဈေးနှုန်းကို ဘယ်လိုသိနိုင်မလဲ?

လိုချင်တဲ့ မော်ဒယ် သို့မဟုတ် အသုံးပြုပုံနဲ့ ဘတ်ဂျက်ကို ပြောပြပါ။ လက်ရှိရရှိနိုင်တဲ့ ဈေးနှုန်းကို ပြန်လည်အတည်ပြုပေးပါမယ်။

Graphic Design အတွက် စက်ရွေးပေးနိုင်ပါသလား?

အသုံးပြုမယ့် Design Software၊ ဖိုင်အရွယ်အစားနဲ့ အလုပ်ပမာဏကို သိရှိပြီးမှ လိုအပ်တဲ့ Specification ကို ဆွေးနွေးနိုင်ပါတယ်။

အာမခံ ဘယ်လောက်ပေးပါသလဲ?

အာမခံကာလနဲ့ အကျုံးဝင်မှုဟာ ပစ္စည်းအမှတ်တံဆိပ်၊ မော်ဒယ်နဲ့ Supplier စည်းကမ်းအလိုက် ကွာခြားနိုင်တာကြောင့် မဝယ်ယူမီ အတည်ပြုပေးပါမယ်။

IT Garden ကို ဆက်သွယ်ရန်

သင့်အတွက် သင့်တော်တဲ့ စက်ကို အတူရွေးချယ်ကြမယ်။

လိုချင်တဲ့ Desktop၊ Laptop အမျိုးအစား၊ အသုံးပြုမယ့် ရည်ရွယ်ချက်နဲ့ ဘတ်ဂျက်ကို ပြောပြပါ။ မော်ဒယ်နဲ့ လက်ရှိဈေးနှုန်းကို စုံစမ်းပေးပါမယ်။
